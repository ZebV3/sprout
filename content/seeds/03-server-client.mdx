## The idea

In the App Router, components are **Server Components by default**. They render on the server and send no JavaScript to the browser. Add `'use client'` at the top of a file only when you need state, effects, or browser APIs.

```tsx
'use client';

import { useState } from 'react';

export function LikeButton() {
  const [liked, setLiked] = useState(false);
  return <button onClick={() => setLiked(!liked)}>{liked ? 'Liked' : 'Like'}</button>;
}
```

## Key points

- `'use client'` marks a boundary: that file and everything it imports become client code.
- Push the boundary down. Make the small interactive piece a Client Component, not the whole page.
- Server Components can render Client Components. A Client Component can receive Server Components as `children`.
- Use hooks (`useState`, `useEffect`) and event handlers only in Client Components.

<Callout>Smaller client boundary, less JavaScript, faster pages.</Callout>
