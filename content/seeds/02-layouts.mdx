## The idea

A `layout.tsx` wraps every page below it. When you move between pages that share a layout, the layout is not remounted, so its state survives.

```tsx
// src/app/dashboard/layout.tsx
export default function DashboardLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <div className="flex">
      <aside>Sidebar</aside>
      <section>{children}</section>
    </div>
  );
}
```

## Key points

- Layouts nest: the root layout wraps the dashboard layout, which wraps the page.
- The root layout must contain `<html>` and `<body>`.
- Use `template.tsx` when you want a fresh instance on every navigation.
- Layouts cannot read the current pathname or search params directly.

<Callout>Layouts are for UI that stays. Templates are for UI that resets.</Callout>
